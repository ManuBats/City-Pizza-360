# City-Pizza-360

Sistema integral City Pizza Center — San Vicente de Cañete.
Flujo: Menú -> Carrito -> Checkout invitado -> Tracking -> KDS -> Delivery -> Inventario -> Reportes.

## Estructura
- `City-pizza-backend/` — NestJS 10 + Prisma + PostgreSQL (Supabase)
- `City-pizza-frontend/` — Next.js 14 + Tailwind (Vercel)

## Dev
```bash
# backend
npm run dev
# frontend
npm run dev
```
